# SimpleOCR

Лёгкое десктопное приложение для Windows: копирование текста с любой
картинки или области экрана через **встроенный OCR Windows**
(`Windows.Media.Ocr`). Без облака, без интернета, без сторонних OCR-движков.

## Возможности

- **Захват области экрана** — глобальная горячая клавиша `Ctrl+Shift+S`:
  экран затемняется, мышью выделяется прямоугольник (как «Ножницы»).
- **OCR из файла** — `.png .jpg .jpeg .bmp .webp .tiff`.
- **OCR из буфера обмена** — распознавание картинки из буфера.
- **Авто-определение языка** из установленных пакетов Windows
  (по умолчанию русский → английский).
- Редактируемое поле результата, **авто-копирование** в буфер +
  кнопка «Скопировать снова».
- **История** последних 10 распознаваний (клик восстанавливает текст).
- **Системный трей**: фоновая работа, хоткей доступен всегда.
- Проверка языковых пакетов при запуске с инструкцией по установке.

## Системные требования

- **Windows 10 build 1809 (1809+) или Windows 11.**
  `Windows.Media.Ocr` доступен начиная с Windows 10 1809.
- Python **3.11+** (только для запуска из исходников; в собранном
  `.exe` Python не нужен).

## Установка языкового пакета OCR (важно!)

OCR работает только для языков, чьи пакеты распознавания установлены:

1. «Параметры» Windows (`Win + I`).
2. **Время и язык → Язык и регион** (Time & Language → Language).
3. **Добавить язык** (Add a language) → выберите **Русский**.
4. Откройте язык → **Параметры** → **Дополнительные компоненты**
   → установите **«Базовый набор для ввода»** (Optional features →
   Basic typing). Именно он содержит OCR-модель.
5. Перезапустите SimpleOCR.

Английский (`en-US`) обычно установлен по умолчанию.

## Запуск из исходников

```bat
cd ocr_app
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Тест OCR-движка отдельно:

```bat
python -m core.ocr_engine        :: распознаёт тестовые ru/en картинки
python -m core.language_check    :: показывает установленные OCR-языки
```

## Сборка .exe (PyInstaller)

```bat
pip install pyinstaller
pyinstaller build.spec
```

Либо одной командой:

```bat
pyinstaller --onefile --windowed --icon=resources/icon.ico main.py
```

Готовый файл — `dist\SimpleOCR.exe` (≈20–40 МБ, один файл, без консоли).

## Данные приложения

Настройки и история хранятся в `%APPDATA%\SimpleOCR\`:

- `settings.json` — язык OCR, горячая клавиша, авто-копирование, трей;
- `history.json` — последние 10 распознаваний.

## Структура

```
ocr_app/
├── main.py                  точка входа
├── requirements.txt
├── build.spec               конфиг PyInstaller
├── ui/
│   ├── main_window.py       окно, трей, история, OCR-поток
│   ├── snip_overlay.py      затемнение + выделение области
│   └── settings_dialog.py   язык / хоткей / поведение
├── core/
│   ├── ocr_engine.py        обёртка над winsdk (sync поверх async)

│   ├── history.py           JSON в %APPDATA%/SimpleOCR/
│   └── language_check.py    проверка OCR-языков
└── resources/icon.ico
```

## Замечания

- OCR выполняется в `QThread` — интерфейс не зависает.
- Горячая клавиша работает и когда окно свёрнуто в трей.
- Закрытие окна сворачивает в трей (отключается в настройках); полный
  выход — пункт «Выход» в меню трея.
- Для смены языка вручную: «Настройки» → «Язык OCR» (список берётся из
  `OcrEngine.available_recognizer_languages`).
